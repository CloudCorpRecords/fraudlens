# FraudLens — Demo Walkthrough Script (≈3 minutes)

**Setup (before recording / presenting):**
```bash
cd wave-datanova
python3 run.py                                            # regenerate + retrain + rebuild dashboard data
python3 -m http.server 8000 --directory dashboard         # then open http://localhost:8000
```

**Script**

1. **The problem (0:00–0:30)** — "Payment fraud is rare, fast and expensive.
   Analysts drown in alerts from black-box systems they can't explain to
   customers or regulators. FraudLens answers two questions for every single
   transaction: *how risky is this?* and *why do we think so?*"

2. **The data (0:30–0:50)** — Show the header strip. "Everything you see is a
   real output of the pipeline, run just now on 8,000 synthetic transactions
   generated by a seeded script — about 2% fraud, modelled on stolen-card
   behaviour: foreign country, unknown device, burst velocity, night hours.
   Synthetic means zero privacy risk and anyone can reproduce our numbers."

3. **The scoreboard (0:50–1:30)** — Point at the metric cards and the
   Model-vs-Rules table. "On a held-out test set the model was never trained
   on, FraudLens beats the rules-only baseline that most small processors
   still run — and the confusion matrix shows the exact trade-off in both
   directions: fraud caught, false alerts, and the honest misses."

4. **The trade-off, live (1:30–2:10)** — Drag the threshold slider down:
   recall climbs, precision falls, alert count grows. Drag it up: the
   opposite. "This is the dial a fraud team tunes to its staffing. It's
   recomputed live from the real test scores embedded in the page — nothing
   here is a screenshot of a result, it *is* the result."

5. **The explanation (2:10–2:40)** — Scroll to the feature-driver bars.
   "Every driver is a model coefficient a human can read: unknown device,
   country mismatch, burst velocity push risk up; account age pushes it
   down. That list becomes the reason codes on each alert in the flagged
   table below — no black box."

6. **Close (2:40–3:00)** — "FraudLens is 100% standard-library Python and a
   static dashboard: it runs anywhere, audits end-to-end from
   `test_predictions.csv`, and is MIT-licensed. Interpretable isn't a
   compromise — on this benchmark it's also the better detector."
